# 08 - Arquitectura Propuesta

- **Estructura de Directorios**:
  - `db/schema.sql`: Definición DDL de la base de datos.
  - `knowledge-base/`: Documentación canónica del proyecto.
  - `openspec/`: Especificaciones de OpenSpec para gestión de cambios.
- **Seguridad y Variables de Entorno**:
  - `.env.example`: Plantilla para configuración de conexión a base de datos.
