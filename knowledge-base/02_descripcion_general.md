# 02 - Descripción General

## Stack Tecnológico
- **Base de Datos**: PostgreSQL (o compatible SQL estándar).
- **Lenguaje de Definición de Datos (DDL)**: SQL.

## Arquitectura General
El proyecto se compone de un esquema relacional centralizado en una base de datos SQL (`db/schema.sql`) que define las tablas relacionales y sus restricciones de integridad.

## Integraciones Externas
- Ninguna en la versión actual (modelo puramente relacional backend/SQL).
